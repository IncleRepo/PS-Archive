# 941. Valid Mountain Array

- 난이도: Easy
- 원문: <https://leetcode.com/problems/valid-mountain-array/>

## 문제

정수 배열 `arr`가 주어진다.

배열의 길이가 3 이상이고, 처음부터 어떤 정상까지는 값이 엄격하게 증가하며 정상부터 마지막까지는 엄격하게 감소하면 유효한 산 배열이다.

정상은 배열의 처음이나 끝에 있을 수 없다. `arr`가 유효한 산 배열이면 `true`, 아니면 `false`를 반환하라.

## 예제 1

```text
입력: arr = [2,1]
출력: false
```

배열의 길이가 3보다 작으므로 산 배열이 아니다.

## 예제 2

```text
입력: arr = [3,5,5]
출력: false
```

같은 값이 연속하므로 엄격하게 증가하거나 감소하지 않는다.

## 예제 3

```text
입력: arr = [0,3,2,1]
출력: true
```

`0`에서 `3`까지 증가한 뒤 `1`까지 계속 감소한다.

## 제약 조건

- `1 <= arr.length <= 10^4`
- `0 <= arr[i] <= 10^4`
