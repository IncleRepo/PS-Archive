# 1051. Height Checker

- 난이도: Easy
- 원문: <https://leetcode.com/problems/height-checker/>

## 문제

학생들이 현재 서 있는 순서대로 키를 담은 정수 배열 `heights`가 주어진다.

학생들이 키의 비내림차순으로 서 있을 때의 배열을 `expected`라고 하자.

현재 위치의 키 `heights[i]`와 올바르게 정렬된 위치의 키 `expected[i]`가 다른 인덱스의 개수를 반환하라.

## 예제 1

```text
입력: heights = [1,1,4,2,1,3]
출력: 3
```

정렬된 배열은 `[1,1,1,2,3,4]`이며 인덱스 2, 4, 5의 값이 다르다.

## 예제 2

```text
입력: heights = [5,1,2,3,4]
출력: 5
```

정렬된 배열 `[1,2,3,4,5]`와 비교하면 모든 위치의 값이 다르다.

## 예제 3

```text
입력: heights = [1,2,3,4,5]
출력: 0
```

이미 비내림차순으로 정렬되어 있으므로 다른 위치가 없다.

## 제약 조건

- `1 <= heights.length <= 100`
- `1 <= heights[i] <= 100`
