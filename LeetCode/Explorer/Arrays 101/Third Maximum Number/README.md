# 414. Third Maximum Number

- 난이도: Easy
- 원문: <https://leetcode.com/problems/third-maximum-number/>

## 문제

정수 배열 `nums`가 주어진다.

배열에서 서로 다른 값만 셌을 때 세 번째로 큰 값을 반환하라.

서로 다른 값이 세 개보다 적다면 배열의 최댓값을 반환한다.

## 예제 1

```text
입력: nums = [3,2,1]
출력: 1
```

서로 다른 값을 큰 순서로 나열하면 `3,2,1`이므로 세 번째 최댓값은 `1`이다.

## 예제 2

```text
입력: nums = [1,2]
출력: 2
```

서로 다른 값이 두 개뿐이므로 최댓값 `2`를 반환한다.

## 예제 3

```text
입력: nums = [2,2,3,1]
출력: 1
```

중복된 `2`를 한 번만 세면 서로 다른 값은 `3,2,1`이다.

## 제약 조건

- `1 <= nums.length <= 10^4`
- `-2^31 <= nums[i] <= 2^31 - 1`

## 추가 조건

`O(n)` 시간에 해결할 수 있는지도 생각해보라.
