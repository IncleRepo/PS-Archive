# 977. Squares of a Sorted Array

- 난이도: Easy
- 원문: <https://leetcode.com/problems/squares-of-a-sorted-array/>

## 문제

비내림차순으로 정렬된 정수 배열 `nums`가 주어진다.

각 원소를 제곱한 값들로 이루어진 배열을 비내림차순으로 정렬해 반환하라.

## 예제 1

```text
입력: nums = [-4,-1,0,3,10]
출력: [0,1,9,16,100]
```

각 원소를 제곱하면 `[16,1,0,9,100]`이 되고, 이를 정렬하면 `[0,1,9,16,100]`이 된다.

## 예제 2

```text
입력: nums = [-7,-3,2,3,11]
출력: [4,9,9,49,121]
```

## 제약 조건

- `1 <= nums.length <= 10^4`
- `-10^4 <= nums[i] <= 10^4`
- `nums`는 비내림차순으로 정렬되어 있음

## 추가 조건

각 원소를 제곱한 뒤 정렬하면 쉽게 풀 수 있다. 다른 접근으로 `O(n)` 시간에 해결할 수 있는지도 생각해보라.
