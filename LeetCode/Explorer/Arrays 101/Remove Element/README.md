# 27. Remove Element

- 난이도: Easy
- 원문: <https://leetcode.com/problems/remove-element/>

## 문제

정수 배열 `nums`와 정수 `val`이 주어진다.

배열에서 `val`과 같은 값을 모두 제자리에서 제거하고, `val`과 다른 원소의 개수 `k`를 반환하라.

반환 후 `nums`의 앞 `k`개 위치에는 `val`과 다른 원소들이 들어 있어야 한다. 원소의 순서는 바뀌어도 되며, `k` 이후의 값은 중요하지 않다.

## 예제 1

```text
입력: nums = [3,2,2,3], val = 3
출력: 2, nums = [2,2,_,_]
```

`3`을 모두 제거하면 남는 원소는 `2,2`이므로 `k`는 2다.

## 예제 2

```text
입력: nums = [0,1,2,2,3,0,4,2], val = 2
출력: 5, nums = [0,1,3,0,4,_,_,_]
```

`2`가 아닌 원소는 `0,1,3,0,4`로 총 5개다. 앞의 5개 원소가 이 값들을 포함하면 되고, 그 뒤의 값은 상관없다.

## 제약 조건

- `0 <= nums.length <= 100`
- `0 <= nums[i] <= 50`
- `0 <= val <= 100`
