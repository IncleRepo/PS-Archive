# Arrays 101 학습노트

문제를 읽고 풀이를 떠올리는 데 필요한 내용만 정리한다.

## 문제에서 풀이 떠올리기

### 1. 개수·연속 구간·증가/감소를 구한다

- 문제 모습: 조건에 맞는 숫자 개수, 연속된 `1`의 최대 길이, 산 모양 배열인지 확인
- 먼저 할 일: 왼쪽부터 한 번 보면서 개수, 현재 연속 길이, 진행 방향을 갱신한다.

### 2. 값을 제거·이동하거나 두 종류로 나눈다

- 문제 모습: 특정 값 제거, 중복 제거, `0`을 뒤로 이동, 짝수를 앞으로 이동
- 먼저 할 일: 남길 값을 왼쪽 빈자리부터 쓴다. 기존 순서가 상관없으면 교환한다.

### 3. 정렬 배열을 다루거나 값을 오른쪽으로 민다

- 문제 모습: 정렬된 값의 제곱, 두 정렬 배열 병합, 고정 길이 배열에서 `0` 복제
- 먼저 할 일: 양끝을 비교한다. 앞에서 쓰면 원본이 덮이는 문제는 뒤에서 채운다.

### 4. 두 값의 관계나 사라진 값을 찾는다

- 문제 모습: 한 값이 다른 값의 두 배인지 확인, `1..n` 중 등장하지 않은 값 찾기
- 먼저 할 일: 본 값을 `Set`에 저장한다. 값이 `1..n`이면 `값 - 1` 위치에 방문 표시한다.

### 5. 기준이 되는 값과 비교한다

- 문제 모습: 오른쪽 최댓값으로 교체, 정렬했을 때 다른 위치 세기, 서로 다른 세 번째 최댓값 찾기
- 먼저 할 일: 오른쪽부터 최댓값을 갱신하거나, 정렬 복사본 또는 상위 3개 후보를 유지한다.

## Java 코딩 포인트

- 배열: 길이는 `nums.length`, 복사는 `nums.clone()`, 정렬은 `Arrays.sort(nums)`
- 숫자: 최댓값은 `Math.max(a, b)`, 절댓값은 `Math.abs(x)`
- 집합: `HashSet`의 `add`, `contains`, `remove`로 중복 없는 후보를 관리
- 목록: `ArrayList`의 `add`로 반환할 값을 순서대로 저장
- 집합의 최댓값·최솟값: `Collections.max(set)`, `Collections.min(set)`
- 값만 읽으면 `for (int x : nums)`, 인덱스·이웃·수정이 필요하면 기본 `for`문 사용

## 구현할 때 주의

- Java 배열은 길이가 고정이므로 삭제할 값 대신 남길 값을 앞으로 덮어쓴다.
- 배열을 대입하면 같은 배열을 가리킨다. 원본을 보존하려면 `clone()`으로 복사한다.
- 향상된 `for`문의 변수 값을 바꿔도 원본 배열은 바뀌지 않는다.
- `Set`은 중복을 제거하지만 원소 순서를 보장하지 않는다.
- 인덱스 범위와 `int` 연산의 오버플로를 확인한다.
