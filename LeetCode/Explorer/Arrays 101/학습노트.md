# Arrays 101 학습노트

문제 모습과 핵심 기법을 연결하고, 구현에 필요한 Java 사용법만 짧게 복습한다.

## 문제를 보면 떠올릴 기법

### 1. 개수·연속 구간·증가/감소를 구한다

- 문제 모습: 조건에 맞는 숫자 개수, 연속된 `1`의 최대 길이, 산 모양 배열인지 확인
- 핵심 기법: **선형 탐색·상태 갱신** — 배열을 한 번 훑으면서 개수, 현재 연속 길이, 최댓값, 진행 방향을 갱신한다.

### 2. 값을 제거·이동하거나 두 종류로 나눈다

- 문제 모습: 특정 값 제거, 중복 제거, `0`을 뒤로 이동, 짝수를 앞으로 이동
- 핵심 기법: **읽기/쓰기 포인터·제자리 파티션** — 순서를 유지하면 남길 값을 왼쪽부터 덮어쓰고, 순서가 상관없으면 교환해 두 그룹으로 나눈다.

### 3. 정렬 배열을 다루거나 값을 오른쪽으로 민다

- 문제 모습: 정렬된 값의 제곱, 두 정렬 배열 병합, 고정 길이 배열에서 `0` 복제
- 핵심 기법: **투 포인터·뒤에서 채우기** — 두 인덱스로 양끝이나 두 배열을 비교하고, 앞에서 쓰면 원본이 덮일 때는 마지막 위치부터 확정한다.

### 4. 두 값의 관계나 사라진 값을 찾는다

- 문제 모습: 한 값이 다른 값의 두 배인지 확인, `1..n` 중 등장하지 않은 값 찾기
- 핵심 기법: **`HashSet` 조회·인덱스 방문 표시** — 지금까지 본 값 중 필요한 짝을 빠르게 찾거나, 값 `x`를 인덱스 `x - 1`과 연결해 등장 여부를 표시한다.

### 5. 기준이 되는 값과 비교한다

- 문제 모습: 오른쪽 최댓값으로 교체, 정렬했을 때 다른 위치 세기, 서로 다른 세 번째 최댓값 찾기
- 핵심 기법: **오른쪽부터 누적·정렬 복사본·상위 k개 유지** — 필요한 기준에 따라 오른쪽 최댓값, 정렬된 기대 상태, 상위 후보만 관리한다.

## Java 코딩 포인트

- 배열: 길이는 `nums.length`, 복사는 `nums.clone()`, 정렬은 `Arrays.sort(nums)`이다. 배열을 대입하면 같은 배열을 가리킨다.
- 반복문: 값만 읽으면 `for (int x : nums)`, 인덱스·이웃·수정이 필요하면 기본 `for`문을 쓴다.
- 집합: `Set<Integer> set = new HashSet<>()`로 만들고 `add`, `contains`, `remove`를 사용한다. 중복은 없지만 순서는 보장되지 않는다.
- 목록: `List<Integer> list = new ArrayList<>()`로 만들고 `add`로 반환할 값을 저장한다.
- 최댓값·최솟값: `Math.max(a, b)`, `Collections.max(set)`, `Collections.min(set)`을 사용한다.
- 절댓값: `Math.abs(x)`를 사용하되, 곱셈과 절댓값에서 `int` 범위를 확인한다.
