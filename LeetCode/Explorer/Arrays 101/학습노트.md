# Arrays 101 학습노트

배열 문제에서 먼저 떠올릴 감각만 짧게 정리한다.

## 왼쪽부터 순서대로 보기

배열을 왼쪽부터 보면서 필요한 값만 계속 업데이트한다.

- 조건에 맞는 개수 세기
- 현재값과 최댓값 갱신
- 연속 구간은 끊기면 초기화

## 투 포인터

정렬 배열, 양끝 비교, 두 배열 병합이 보이면 먼저 의심한다.

- 양끝에서 큰 값 비교
- 두 배열을 동시에 비교
- `O(n)`으로 한 번에 끝내기

## 뒤에서 채우기

앞에서 쓰면 아직 볼 값이 덮일 때 쓴다.

- 제자리 수정
- 뒤에 빈 공간 있음
- 값이 오른쪽으로 밀림
- 큰 값부터 끝에 넣기

## In-place

새 배열 없이 원본을 직접 고치는 문제다.

- 반환값 없이 배열 수정
- 추가 공간 `O(1)` 요구
- 배열 길이 고정
- 덮어쓰기 위험 체크
