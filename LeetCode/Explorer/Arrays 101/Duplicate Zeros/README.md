# 1089. Duplicate Zeros

- 난이도: Easy
- 원문: <https://leetcode.com/problems/duplicate-zeros/>

## 문제

고정 길이의 정수 배열 `arr`가 주어진다.

배열 안의 모든 `0`을 한 번 더 복제하고, 그 뒤의 원소들은 오른쪽으로 한 칸씩 밀어야 한다. 배열의 길이는 고정되어 있으므로, 오른쪽으로 밀려 배열 범위를 벗어나는 원소는 버린다.

이 작업은 입력 배열 `arr` 자체를 수정해야 하며, 별도의 값을 반환하지 않는다.

## 예제 1

```text
입력: arr = [1,0,2,3,0,4,5,0]
출력: [1,0,0,2,3,0,0,4]
```

`0`이 복제되면서 뒤의 원소들이 오른쪽으로 밀리고, 배열 길이를 넘어가는 값은 사라진다.

## 예제 2

```text
입력: arr = [1,2,3]
출력: [1,2,3]
```

복제할 `0`이 없으므로 배열은 그대로 유지된다.

## 제약 조건

- `1 <= arr.length <= 10^4`
- `0 <= arr[i] <= 9`
