# 88. Merge Sorted Array

- 난이도: Easy
- 원문: <https://leetcode.com/problems/merge-sorted-array/>

## 문제

비내림차순으로 정렬된 두 정수 배열 `nums1`, `nums2`와 정수 `m`, `n`이 주어진다.

- `m`은 `nums1`에서 실제로 병합에 사용할 원소 개수다.
- `n`은 `nums2`의 원소 개수다.

두 배열을 하나의 비내림차순 배열로 병합하라.

최종 결과는 새 배열로 반환하지 않고, `nums1` 안에 직접 저장해야 한다. 이를 위해 `nums1`의 길이는 `m + n`이며, 앞의 `m`개 원소만 유효한 값이고 뒤의 `n`개 `0`은 병합을 위한 빈 공간으로 취급한다.

## 예제 1

```text
입력: nums1 = [1,2,3,0,0,0], m = 3, nums2 = [2,5,6], n = 3
출력: [1,2,2,3,5,6]
```

`[1,2,3]`과 `[2,5,6]`을 합쳐 정렬된 상태로 `nums1`에 저장한다.

## 예제 2

```text
입력: nums1 = [1], m = 1, nums2 = [], n = 0
출력: [1]
```

`nums2`가 비어 있으므로 `nums1`은 그대로 유지된다.

## 예제 3

```text
입력: nums1 = [0], m = 0, nums2 = [1], n = 1
출력: [1]
```

`nums1`에는 유효한 원소가 없고 빈 공간만 있으므로, `nums2`의 값이 들어간다.

## 제약 조건

- `nums1.length == m + n`
- `nums2.length == n`
- `0 <= m, n <= 200`
- `1 <= m + n <= 200`
- `-10^9 <= nums1[i], nums2[j] <= 10^9`
