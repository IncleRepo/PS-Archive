# 26. Remove Duplicates from Sorted Array

- 난이도: Easy
- 원문: <https://leetcode.com/problems/remove-duplicates-from-sorted-array/>

## 문제

비내림차순으로 정렬된 정수 배열 `nums`가 주어진다.

각 값이 한 번씩만 나타나도록 중복 원소를 제자리에서 제거하고, 서로 다른 원소의 개수 `k`를 반환하라.

반환 후 `nums`의 앞 `k`개 위치에는 서로 다른 원소들이 기존 순서를 유지한 채 들어 있어야 한다. `k` 이후의 값은 중요하지 않다.

## 예제 1

```text
입력: nums = [1,1,2]
출력: 2, nums = [1,2,_]
```

서로 다른 원소는 `1,2`이므로 `k`는 2다.

## 예제 2

```text
입력: nums = [0,0,1,1,1,2,2,3,3,4]
출력: 5, nums = [0,1,2,3,4,_,_,_,_,_]
```

서로 다른 원소 `0,1,2,3,4`를 배열 앞쪽에 저장하므로 `k`는 5다.

## 제약 조건

- `1 <= nums.length <= 3 * 10^4`
- `-100 <= nums[i] <= 100`
- `nums`는 비내림차순으로 정렬되어 있음
