# 283. Move Zeroes

- 난이도: Easy
- 원문: <https://leetcode.com/problems/move-zeroes/>

## 문제

정수 배열 `nums`가 주어진다.

0이 아닌 원소들의 상대적인 순서를 유지하면서 모든 `0`을 배열의 끝으로 이동하라.

새 배열을 만들지 않고 입력 배열 `nums`를 직접 수정해야 한다.

## 예제 1

```text
입력: nums = [0,1,0,3,12]
출력: [1,3,12,0,0]
```

0이 아닌 `1,3,12`의 순서는 유지되고 두 개의 `0`은 배열 끝으로 이동한다.

## 예제 2

```text
입력: nums = [0]
출력: [0]
```

원소가 `0` 하나뿐이므로 배열은 그대로 유지된다.

## 제약 조건

- `1 <= nums.length <= 10^4`
- `-2^31 <= nums[i] <= 2^31 - 1`

## 추가 조건

전체 대입 연산의 수를 최소화할 수 있는지도 생각해보라.
