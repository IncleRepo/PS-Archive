# 905. Sort Array By Parity

- 난이도: Easy
- 원문: <https://leetcode.com/problems/sort-array-by-parity/>

## 문제

정수 배열 `nums`가 주어진다.

모든 짝수가 모든 홀수보다 앞에 오도록 배열을 재배치해서 반환하라.

짝수끼리 또는 홀수끼리의 순서는 상관없으며, 조건을 만족하는 배열이면 모두 정답이다.

## 예제 1

```text
입력: nums = [3,1,2,4]
출력: [2,4,3,1]
```

짝수 `2,4`가 홀수 `3,1`보다 앞에 있다. 각 그룹 안의 순서는 달라도 된다.

## 예제 2

```text
입력: nums = [0]
출력: [0]
```

`0`은 짝수이므로 배열은 그대로 조건을 만족한다.

## 제약 조건

- `1 <= nums.length <= 5000`
- `0 <= nums[i] <= 5000`
