# PS-Archive

알고리즘 문제 풀이를 정리하는 저장소입니다.

목표는 문제를 다시 봤을 때 풀이 감각을 빠르게 되살리는 것입니다.

## 구성

- `LeetCode/`: LeetCode 풀이
  - `Explorer/Arrays 101/`: LeetCode Explore Arrays 101 문제
- `CodeForces/`: Codeforces 풀이

## 정리 방식

문제별 폴더에는 다음 내용을 둡니다.

- `README.md`: 문제를 한국어로 짧게 정리
- `Solution.java`: 풀이 코드와 핵심 주석

풀이 코드 위에는 다음 두 가지를 짧게 남깁니다.

- 문제를 푸는 아이디어
- 코딩 테스트에서 기억할 일반적인 포인트

단원 폴더에는 필요하면 학습노트를 둡니다.

- 예: `LeetCode/Explorer/Arrays 101/학습노트.md`

학습노트는 긴 설명보다, 문제를 보고 어떤 풀이 패턴을 떠올릴지에 집중합니다.

## 학습노트 작성 규칙

학습노트는 1~2분 안에 전체를 복습할 수 있는 분량으로 작성합니다.

다음 구조를 모든 단원에서 동일하게 사용합니다.

```markdown
# [단원명] 학습노트

[이 노트에서 복습할 내용을 한 문장으로 작성]

## 문제에서 풀이 떠올리기

### 1. [문제 유형을 짧게 요약]

- 문제 모습: [실제 문제에서 요구하는 상황]
- 먼저 할 일: [가장 먼저 떠올릴 풀이 패턴]

## [사용 언어] 코딩 포인트

- [이번 단원에서 실제 사용한 자료구조·메서드·문법]

## 구현할 때 주의

- [반복해서 실수할 수 있는 경계 조건이나 언어 특성]
```

작성할 때는 다음 원칙을 지킵니다.

- `문제 모습`은 실제 문제를 읽는 것처럼 구체적으로 씁니다.
- `먼저 할 일`에는 다른 문제에도 재사용할 수 있는 풀이 패턴을 씁니다.
- 완성 코드, 긴 예제, 문제별 상세 설명은 넣지 않습니다.
- 자료구조와 문법은 해당 단원에서 실제 사용한 것만 추가합니다.
- 특정 문제에만 필요한 설명은 문제 폴더의 `README.md`와 `Solution.java`에 둡니다.
